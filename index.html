Condivisione tra tablet e telefoni

Turni, nomi, promemoria e foto vengono salvati nel vostro repository GitHub (nel ramo "dati"), così sono uguali su tutti i dispositivi collegati. Ogni dispositivo va collegato una volta sola.
  1. Apri questa pagina di GitHub (va bene anche dal telefono)
  2. Nome: HomeDashboard · Scadenza: la più lunga possibile
  3. Repository access: Only select repositories → HomeDashboard
  4. Permissions: Contents → Read and write, poi Generate token
  5. Copia il codice (inizia con github_pat_) e incollalo qui sotto
Manda questo link all'altro telefono: si apre la versione per smartphone già collegata, senza fare altro.
Per averla tra le app: Android menu ⋮ → "Aggiungi a schermata Home"; iPhone Condividi → "Aggiungi alla schermata Home", poi nell'app ⚙ → incolla il codice qui sotto (su iPhone l'app installata non vede il link).
